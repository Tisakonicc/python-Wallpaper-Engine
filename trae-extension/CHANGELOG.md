# Changelog

本文件记录 `trae-extension`（Background-Wallpaper-Engine）的版本变化。
更早的版本（0.1.5–0.2.14）见 [GitHub Releases](https://github.com/Tisakonicc/python-Wallpaper-Engine/releases)。

## 0.4.17

- 网页壁纸降载改为保守策略：前 3 秒预热不判断，之后连续三轮低于 45fps 才降 DPR；
  30fps 仅在 DPR 降完、连续三轮低于 30fps 且距降 DPR 超过 4 秒时启用。
- 新增 `web-fps` 基线诊断；页面没有 rAF 动画时跳过降载判断。
- 面板硬解状态同步改为首次打开面板后才启动定时器；焦点兜底轮询 500ms → 1s。
- 缓存硬解状态每 15 秒重报时，值没变不再写 `diag.log`。
- `product.json` 写回复用已读取内容里的换行信息，避免重复读取 78 KB。
- 新增 `src/ide.js`，集中 `flavorOf()` / `proxyNamespace()`；扩展与本地服务共用。
- `RUNTIME_REV` 升到 6：升级后需要重载一次窗口完成重注入。

## 0.4.16

- 修复切换壁纸后旧网页壁纸音乐继续播放：换壁纸 / 禁用 / 渲染失败回退前，先暂停旧 iframe 内的
  `<audio>`、`<video>` 和 `new Audio()` 实例，清空 `src` 并 `load()`，再拆除 iframe。
- 引擎挂在 `media` 容器上的音频元素一并停止，避免父窗口 `AudioContext` 的
  `createMediaElementSource` 音频图继续出声。

## 0.4.15

- 网页壁纸自适应降载：统计 iframe 内真实 rAF 帧率；连续两轮低于 45fps 时把 `devicePixelRatio`
  固定为 1 并触发 resize，canvas 像素数降到 1/4；仍低于 38fps 时把 rAF 限到约 30fps。
- 只在壁纸可见、未暂停时判断，避免把最小化期间的系统限帧误判成卡顿；降载后本次页面生命周期内不再回升。
- 同帧多个 rAF 回调按时间戳去重计数，避免多循环导致 fps 虚高。

## 0.4.14

- 启动链路：`/render/live.html` 发现 app 不匹配时返回一个会立刻 `postMessage` 的小页面，
  注入脚本马上换端口，不再每个错误端口等满 4 秒。
- 端口黑名单：本轮启动跳过已经确认属于其它 IDE / 不通的端口，避免反复撞 32123；30 秒后自动解除。
- 稳定性：已经收到渲染页 boot、但 `/state` 尚未返回时额外等 15 秒，不再因为壁纸库扫描慢而误换端口。
- 探活提速：本地 `/health` 超时从 1.5 秒降到 0.6 秒。
- boot 回带导航序号 `a`，迟到的旧导航消息会被丢弃。
- 注入修订号 `RUNTIME_REV` 升到 5：升级后需要重载一次窗口完成重注入。

## 0.4.13

- 硬解判断改用 `navigator.mediaCapabilities.decodingInfo` 的 `powerEfficient`，不再依赖自造 H.264 样本；
  修正样本被 Chromium 判为 `Unsupported configuration` 时一律显示「软解」的误判。旧内核没有该 API
  时才退回 WebCodecs 实测。
- 徽章补全状态：探测结果没送到面板时显示「未连接」；当前壁纸不是视频时显示「不适用」。
- 渲染页每 15 秒重报一次缓存的探测结果，扩展宿主重启后徽章自动恢复。
- 非属主窗口从 `/state.json` 同步 `hwDecode`，修掉多窗口下徽章一直停在「未连接」的问题。
- `diag.log` 超过 8 MB 自动轮转为 `diag.log.1`；超过 32 MB 的旧文件直接清空，避免继续占盘。

## 0.4.12

- 修复注入块 `app` 字段路径被转义错误，导致重载窗口后背景不自动显示、需要手动重新注入的问题。
- 移除自动添加的面板底衬，底衬强度恢复由用户滑块控制。
- 解码状态「检测中」增加 10 秒超时兜底，避免连接失败时一直闪烁。

## 0.4.11

- 文字增强三层强化：42% 透明度主题色底衬、强制前景色、四层阴影加细描边，亮壁纸上的文字更醒目。
- 只覆盖前景色与阴影，不修改语法高亮的 token 配色。

## 0.4.10

- 修复 VS Code 下文字增强不生效：改用渲染页上报的 `themeKind` 判断主题，不再依赖 `body.vs-dark` /
  `body.vs-light` 类名；CSS 变量同时写入 `html` 与 `.monaco-workbench` 两层。
- 注入脚本按独立修订号决定是否重写，普通升级不再反复提示重启。

## 0.4.8

- 重启提示去掉「破损」等负面表述，改为「背景层需要重启一次 IDE 才能完成加载」，按钮改为「重启 IDE / 稍后」。
- 0.4.7 起只要已有注入块就算已注入，升级不再重写 `workbench.html`。

## 0.4.7

- 拦截网页壁纸脚本里每 3 秒自动重试的 `play()`，修复窗口最小化期间音乐断断续续。
- 注入判定改为「已存在注入块即视为已注入」，修复需要完全重启才能继续的死循环。

## 0.4.6

- 修复窗口最小化 / 后台任务时壁纸音乐断续：隐藏时立即静音并 `pause`，不再依赖 0.6 秒轮询里的延迟暂停；
  隐藏期间音量与曲目属性不重复下发，恢复播放加 350ms 防抖。
- 暂停逻辑只依据窗口是否最小化；窗口仍可见时切换应用、点击或拖动桌面图标，音乐保持播放。

## 0.4.5

- 注入拆成两步：第一次启动只从 `product.json` 的 `checksums` 移除 `workbench.html` 并提示完全重启；
  完全重启后才写入注入块。彻底消除「安装似乎损坏」提示。
- 用主进程 PID 区分窗口重载与完全重启，升级时不再错误还原注入。

## 0.4.3

- 硬解探针调整：使用 16×16 Constrained Baseline 的 Annex-B 样本实测，失败时输出具体原因，
  便于区分「没有 WebCodecs」和「样本不被当前后端接受」。

## 0.4.2

- 面板底部新增解码状态徽章：检测中（灰色脉冲）、硬解（绿色）、软解（琥珀色）；软解时悬停显示探测失败原因。
- 数据链路：渲染页实测后上报服务端，状态变化推送到面板自动刷新。

## 0.4.1

- 新增 WebCodecs 实测硬解探测：实际解码一帧，仅在成功时判定硬解可用。
- 硬解可用时直接播放原片、跳过代理；不可用时回退 720p 代理软解兜底。
- 服务端按请求的 `hw` 参数决定返回原片还是代理文件。

## 0.4.0

- 修复 VS Code 视频壁纸无声：修正 `diagSent` 重复声明导致音频 fallback 不触发的问题，
  并将音频转码从 Opus 改为 Chromium 原生支持的 Vorbis；旧 Opus 缓存自动失效。
- VS Code 端首次播放视频时自动生成 720p 代理，就绪后自动切换，缓解 1080p / 4K 视频
  在软件解码下的卡顿。
- 新增代理画质下拉框，可选 1080p / 720p / 480p / 原视频（清除代理）；代理缓存按
  `proxy/vscode/` 与 `proxy/trae/` 隔离，Trae 默认继续使用原片。
- 诊断日志改为按 step 独立节流，新增编解码器能力探测及 `video-pause` / `waiting` /
  `seeking` 事件记录。

## 0.3.3

- 修复自定义自绘下拉组件在暗色主题下选项文字看不清的问题（网页壁纸音乐切换与壁纸轮播均使用）。
- 网页壁纸切换背景音乐时，除了引擎 `setProperties`，还会每 600ms 持续重投一次并直接调用
  iframe 内 `wallpaperPropertyListener.applyUserProperties`，防止引擎在 iframe 就绪后用
  `project.json` 默认值覆盖用户选择。
- 失焦暂停时音频先快速 fade-out（~80ms）再 pause，恢复时先 resume 再 fade-in，
  避免直接硬切产生"滋"的爆音；视频、场景引擎、网页 iframe 内音频全部覆盖。

## 0.3.2

- 修复网页壁纸切换背景音乐不生效：引擎在 iframe 加载完成时会用 `project.json` 里的
  默认属性覆盖一次，导致只投递一次的曲目被打回默认。现在网页壁纸会持续重新投递，
  并同时调用页面自己的 `wallpaperPropertyListener`。

## 0.3.1

- 「播放」页新增**背景音乐下拉框**：场景 / 网页壁纸自带多首音乐时可在面板里切换曲目。
  不再只认 `general.properties.music`，会按属性名（music / bgmTrack / song / track…）
  和显示文字自动识别音乐 combo，并按识别到的属性名下发给场景脚本。
- 「播放」页新增**壁纸轮播**：勾选后按可调间隔（1–120 分钟）在壁纸库中自动轮换。
- 切换壁纸时若旧曲目值不在新壁纸的选项里，会自动清空，避免串台。

## 0.2.29

- 修复网页壁纸导出时目录名被扩展宿主按 GBK 重编码成乱码的问题：改用 `robocopy` 子进程复制，
  中文路径落盘正确；校验失败时输出面板会打印实际目录名。
- 导出目录名优先取壁纸 `project.json` 的 `title`，不再直接用磁盘文件夹名。

## 0.2.28

- 导入网页壁纸时标题优先取 `project.json` 的 `title`，避免磁盘上的乱码文件夹名带进面板与导出。

## 0.2.27

- 网页壁纸的 html / js / css 改为 `no-store`，iframe 地址带时间戳，修掉改完壁纸后仍跑旧缓存脚本的问题。
- 自动对比度与文字增强改为**默认关闭**（壁纸原样呈现，按需在面板「外观」里开启），
  配置项描述同步说明默认值与适用场景。
